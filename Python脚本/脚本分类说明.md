# Python 脚本分类说明

本文档说明 `d:\deadline520\Python脚本` 下各类脚本的用途，以及它们从旧路径移动到新路径后的对应关系。

## 1. 目录结构

当前自定义 Python 脚本已经按用途整理为：

- `d:\deadline520\Python脚本\01_数据处理`
- `d:\deadline520\Python脚本\02_评估脚本`
- `d:\deadline520\Python脚本\03_可视化与监控`

说明：

- 这里只整理了你自己实验过程中使用的顶层脚本；
- `LLaMA-Factory` 内部源码和测试文件没有移动；
- 后续命令如果还使用旧路径，需要改成新路径。

## 2. 数据处理类

路径：

- `d:\deadline520\Python脚本\01_数据处理`

包含脚本：

- `convert_csqa.py`
  - 用于原始 CSQA 数据转换
- `make_csqa_strict_dataset.py`
  - 生成 strict 路线的数据集
- `make_csqa_tmpl_dataset.py`
  - 生成模板化输出路线的数据集

适用场景：

- 初次准备数据
- 重建 strict 或 tmpl 数据集
- 修改数据模板后重新导出训练/验证集

## 3. 评估脚本类

路径：

- `d:\deadline520\Python脚本\02_评估脚本`

包含脚本：

- `eval_csqa.py`
  - 基础评估脚本
- `eval_csqa_rich.py`
  - strict 主线当前主口径 rich 评估脚本
- `eval_csqa_rich_first_valid.py`
  - strict 路线补充用的 first-valid 口径评估脚本
- `eval_csqa_tmpl_rich.py`
  - 模板输出路线的兼容型评估脚本
- `eval_csqa_tmpl_strict.py`
  - 模板输出路线的严格句式评估脚本

适用场景：

- 评估 baseline
- 评估 LoRA / Full 微调结果
- 生成 rich 评估 JSON
- 对比不同评估口径

## 4. 可视化与监控类

路径：

- `d:\deadline520\Python脚本\03_可视化与监控`

包含脚本：

- `plot_training_metrics.py`
  - 从 `trainer_state.json` 生成训练曲线图
- `run_with_gpu_monitor.py`
  - 训练时记录 GPU 显存占用

适用场景：

- 作业第 1 问训练指标可视化
- 拓展部分的 LoRA / Full 显存对比
